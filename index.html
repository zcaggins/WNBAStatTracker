Where this data comes from Scores, schedule, and play-by-play are fetched live from ESPN's public scoreboard and summary endpoints — the same data sources the open-source wehoop R package wraps for WNBA data. They're unauthenticated and free, but unofficial, undocumented ESPN endpoints, not a guaranteed stable API — ESPN could change or rate-limit them without notice. See README.md for details and a fallback plan.
